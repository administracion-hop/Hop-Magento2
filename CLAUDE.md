# Instrucciones del proyecto

## Especificaciones de componentes

- La especificación de cada componente está en `especificaciones/`; el índice es `especificaciones/INDICE.md`.
- Al empezar cada tarea, leer la especificación de los componentes que toca.
- Cuando un cambio modifica un comportamiento, actualizar la especificación del componente en el mismo pull request.
